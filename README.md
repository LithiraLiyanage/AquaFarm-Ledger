# 🐟 AquaFarm Ledger

**AquaFarm Ledger** is a premium, production-style **full-stack AquaTech SaaS application** built for modern fish farm management.

It helps aquaculture businesses manage **ponds, fish batches, feeding logs, water quality, mortality, harvest planning, alerts, reports, and cost analytics** from one beautiful dashboard.

> 🌊 Built with a purple, black, white and aqua-green SaaS theme to feel like a real startup product.

## 🚀 Key Highlights

- 🎨 **Premium Purple / White / Black SaaS UI** with aqua-green accents  
- 🔐 **JWT Authentication** with role-based access control  
- 👤 User roles: **Farm Owner/Admin**, **Manager**, **Technician**  
- 🏞️ Pond profile management  
- 🐠 Fish batch and stock tracking

## 🧠 Smart Features

| Feature | Description |
|---|---|
| 💧 Water Quality Score | Calculates pond health using pH, temperature, oxygen and ammonia values |

| 📦 Biomass Estimator | Estimates total fish biomass using stock count and average weight |
| 🧾 Cost Analytics | Tracks feed, fingerling, medicine, labor, equipment and maintenance costs |

## ⚡ Quick Start

### 1️⃣ Clone Repository

```bash
git clone https://github.com/LithiraLiyanage/AquaFarm-Ledger.git
cd AquaFarm-Ledger
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
cp .env.example .env
npm run seed
npm run dev
```

Backend runs on:

```txt
http://localhost:5000
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Frontend runs on:

```txt
http://localhost:5173
```

---

## 🔧 Environment Variables

### backend/.env

```txt
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/aquafarm_ledger
JWT_SECRET=change_this_super_secret_key
JWT_EXPIRES_IN=7d
CLIENT_URL=http://localhost:5173
```

### frontend/.env

```txt
VITE_API_URL=http://localhost:5000/api
```
